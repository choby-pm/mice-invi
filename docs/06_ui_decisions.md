# 06. UI 의사결정 · 테마 v1.0 (확정)

> 이 문서는 최초 기획·설계 기준입니다. 현재 구현 범위와 이후 변경은 [현재 상태](current-status.md)를 확인하세요. 기획 확정은 전체 개발 완료를 뜻하지 않습니다.

> **확정: 13가지 모두 추천안, 테마 T1 프로토콜 네이비** (D-UI-11, D-UI-12). 테마 상세는 `07_theme.md`

> ③ UI 의사결정과 ④ 테마 선택을 한 화면에서 진행합니다. 시각 비교·실시간 미리보기: `design/mockups/ui_theme_lab_v0.2.html`
> 기준: 프레임 목업 v0.6 (MVP 55개 화면), 프론트엔드 Tailwind CSS + shadcn/ui (D-UI-01)

## 1. UI 의사결정 13가지

| ID | 항목 | 선택지 | 추천 | 이유 |
|---|---|---|---|---|
| UD-01 | 콘텐츠 폭 | 전체 유동 / 최대 폭 고정 / 화면 성격별 혼합 | **혼합** | 목록·보드는 넓게, 입력·상세는 최대 760~960px |
| UD-02 | PCO 콘솔 메뉴 | 사이드바 펼침 / 사이드바 접힘 / 상단 가로 | **펼침 + 접기 버튼** | 메뉴 13개 이상, 좁은 화면에서 접기 |
| UD-03 | 정보 밀도 | 여유 / 기본 + 표 조밀 전환 / 조밀 | **기본 + 조밀 전환** | 엑셀 사용자는 표에서만 조밀하게 |
| UD-04 | 상세 여는 방식 | 새 페이지 / 옆 패널 / 혼합 | **혼합** | 대표단 360·이슈·하위 행사 = 페이지, 참가자·서비스·요청 = Sheet |
| UD-05 | 상태 표시 | 상태별 색 배지 / shadcn 기본(빨강+모양) / 점+글자 | **상태별 색** | 6개 상태 즉시 구분, 긴급만 가장 강하게 |
| UD-06 | 긴급 강조 | 배지만 / 배지+왼쪽 선 / 행 배경 | **왼쪽 선** | 훑어볼 때 걸리되 무겁지 않게 |
| UD-07 | 필수·선택 표시 | 필수 * / 선택 (optional) / 둘 다 + 안내 | **둘 다** | 비모국어 사용자 오해 방지 |
| UD-08 | 라벨 위치 | 위 / 왼쪽 / 입력칸 안 | **위** | 모바일·다국어에 안전 |
| UD-09 | 결과 알림·확인 창 | 모두 토스트 / 모두 확인 창 / 되돌릴 수 있는지에 따라 | **혼합** | 발송·강제 종결·정산·철회만 확인 창 |
| UD-10 | 글자 크기 (운영/대리인) | 13/15 · 14/16 · 15/17 | **14/16** | 아이폰 입력칸 자동 확대 방지 |
| UD-12 | 다크 모드 | MVP 지원 / 토큰만 준비 / 미지원 | **토큰만 준비** | 1인 검수 부담 감소 |
| UD-13 | 보조 화면 표 (모바일) | 가로 스크롤 / 카드 / 혼합 | **혼합** | 모바일 필수 작업 화면만 카드 |
| UD-14 | 아이콘 | 글자만 / 아이콘+글자 (lucide) / 아이콘 위주 | **아이콘+글자** | shadcn 기본 세트, 단독 아이콘은 툴팁 |

UD-11(컴포넌트 기반)은 D-UI-01로 확정되어 목록에서 제외.

## 2. 테마 후보

| ID | 이름 | 기본색 | 글꼴 | 모서리 | 인상 |
|---|---|---|---|---|---|
| T0 | shadcn 기본 | 무채색 | Inter + Noto Sans KR | 8px | 비교 기준 |
| **T1** | 프로토콜 네이비 (추천) | 짙은 남색 `hsl(215 55% 24%)` | IBM Plex Sans KR | 6px | 공공·외교 행사의 신뢰감 |
| T2 | 클래리티 블루 | 선명한 파랑 `hsl(221 83% 53%)` | Inter + Noto Sans KR | 8px | 익숙한 업무용 SaaS |
| T3 | 세리머니 틸 | 깊은 청록 `hsl(176 62% 25%)` + 따뜻한 바탕 | Gothic A1 | 12px | 의전·환대 분위기 |

모든 테마 공통: 상태 색 토큰(긴급 빨강 · 조치 필요 주황 · 처리중 파랑 · 완료 초록 · 대기 회색), VIP 강조색(금색), 라이트·다크 값 모두 정의.
