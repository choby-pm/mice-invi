## 5. 작업 방식 (의뢰인과의 약속)

### 5.1 검수 루프

1. **작게 나눠서** 구현합니다. 한 번에 한 화면 또는 한 기능.
2. 구현 후 의뢰인이 **직접 눌러볼 수 있는 상태**(로컬 실행 또는 배포 주소)로 만들고 검수를 요청합니다.
3. 검수 요청은 항상 아래 형식으로 합니다.
4. 피드백을 반영하면 `docs/reviews/REVIEW_LOG.md`에 기록하고, 결정은 `DECISION_LOG.md`에 추가합니다.

```
## 🟠 검수 요청: [화면·기능 이름] (릴리스 R?)
- 확인 방법: [주소 또는 실행 방법, 테스트 계정]
- 무엇을 만들었나: [비개발자 언어로 3줄 이내]
- 목업과 다른 점: [있으면 이유와 함께]
- 검수 체크리스트:
  C1. ... (제 기본안: ...)
  C2. ...
- 다음 작업 예정: ...
```

### 5.2 설명 방식

- 의뢰인은 **비개발자**입니다. 쉬운 한국어, 기술 용어는 처음 쓸 때 한 줄로 풀어서.
- 의뢰인에게 터미널 명령을 시킬 때는 **복사해서 붙여넣을 한 줄**과 그 명령이 무엇을 하는지 한 문장.
- 오류가 나면 원인과 해결을 먼저 설명하고, 의뢰인이 할 일이 있으면 번호를 매겨 안내.

### 5.3 테스트를 먼저 쓰는 세 영역 (04 §2.4)

AI가 만든 코드에서 "겉으로는 돌아가는데 규칙이 조용히 빠지는" 위험이 치명적인 곳입니다. 이 세 영역은 **테스트를 먼저 작성하고, 테스트 통과 결과를 의뢰인에게 보여준 뒤** 구현을 검수받습니다.

| 영역 | 먼저 쓸 테스트 |
|---|---|
| 권한·테넌트 격리 | 01 §2.5 권한 매트릭스의 역할 × 데이터 조합 전부. 다른 테넌트·다른 대표단 데이터가 **404**로 막히는지 |
| 영향 엔진 | 도착지 변경 → 항공 → 수송·공항 의전·호텔 → 만찬 판단 → 좌석·식수 5차 연쇄, 재변경 시 무효화·대체 (01 P11, BR-11) |
| 민감정보·파기 | 암호화 저장, 열람 기록 없는 조회 불가, 파기 후 잔존 없음 (03 B10) |

## 6. 목업 → 코드 변환 규칙

`design/mockups/frame_mockup_v0.6.html`은 **배치·문구·상호작용의 기준**이지 코드의 원본이 아닙니다. 아래 규칙으로 옮깁니다.

| 목업 요소 | 코드에서 |
|---|---|
| `.btn .btn-default` 등 | shadcn `Button` (variant: default / outline / secondary / ghost / destructive, size: sm) |
| `.badge`, `.st-*` 상태 배지 | `StatusBadge` 컴포넌트 (07 §3). 목업의 흑백·빨강 표현이 아니라 **T1 상태 색** 적용 |
| `.card` | shadcn `Card` |
| `.tbl` | shadcn `Table` (+ 필요 시 TanStack Table) |
| `.tabs` / 화면 내부 탭 | shadcn `Tabs` |
| `.dlg` 대화상자 | shadcn `Dialog`, 되돌릴 수 없는 행동은 `AlertDialog` (UD-09) |
| 오른쪽 상세 패널 | shadcn `Sheet` (UD-04) |
| ⋯ 메뉴 | shadcn `DropdownMenu` |
| 스위치·라디오·체크 | shadcn `Switch` / `RadioGroup` / `Checkbox` |
| 사이드바 | shadcn `Sidebar` (펼침 기본, 접기 가능 — UD-02) |
| 알림 토스트 | shadcn `Sonner` (되돌릴 수 있는 행동 + 실행 취소 — UD-09) |
| 전체 명단 스프레드시트 | 고정 열·고정 머리글 표. 조회 전용 (D-UI-07·08) |
| 반응형 (컨테이너 쿼리 `@3xl:`) | 화면 폭 기준 Tailwind 반응형으로 변환. 모바일 규칙은 02 §1.12 |
| 검은 원 번호(검수 번호), 오른쪽 검수 패널, 화면 선택기 | **옮기지 않음** (목업 전용) |
| 예시 데이터 (국가·인물·편명) | 개발용 시드 데이터로만. 실존 인물 이름 사용 금지 |
| `data-ko` 영/한 전환 | 다국어 파일(메시지 키)로 분리. 문구를 코드에 직접 쓰지 않음 (02 §1.13) |
