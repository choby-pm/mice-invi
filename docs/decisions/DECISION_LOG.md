# 결정 로그 (Decision Log)

> 프로젝트의 모든 결정을 한곳에 모은 목록입니다. 새 결정은 맨 아래 해당 단계에 추가하고, 기존 결정을 뒤집을 때는 삭제하지 않고 `대체됨`으로 표시한 뒤 새 결정을 추가합니다.

**ID 규칙**: `D-{단계}-{번호}` · PD 문제 정의 / BA 업무·데이터 분석 / UX UX·IA / SY 시스템 / RM 범위·로드맵 / UI UI 디자인

| 상태 | 의미 |
|---|---|
| 확정 | 유효한 결정 |
| 대체됨 | 이후 결정으로 바뀜 (대체한 ID 표시) |
| 보류 | 향후 확인 |
