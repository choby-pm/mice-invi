# 검수 로그 (Review Log)

> 모든 산출물은 **검수 요청 → 피드백 → 수정 → 재검수** 를 반복합니다. 이 파일은 그 기록입니다. 피드백 원문과 반영 내용을 함께 남겨, 왜 이렇게 바뀌었는지 나중에도 추적할 수 있게 합니다.

## 진행 규칙

| 규칙 | 내용 |
|---|---|
| 검수 요청 | Claude가 산출물 버전과 **검수 체크리스트**를 함께 제시 |
| 피드백 | 의뢰인이 체크리스트 번호별로 답하거나 자유롭게 코멘트 |
| 반영 | Claude가 수정 후 버전을 올리고, 무엇을 어떻게 바꿨는지 요약 |
| 결정 기록 | 피드백 중 "결정"에 해당하는 것은 `decisions/DECISION_LOG.md`에도 추가 |
| 통과 | 의뢰인이 "통과" 또는 "다음 단계"라고 하면 해당 산출물 확정 |
