# 대시보드 가독성 개선

- 전체 글꼴을 Pretendard Variable 1.3.9로 교체. 공식 배포 파일과 OFL 라이선스를 저장소에 포함하고 next/font/local로 자체 제공. 기존 Google Fonts 외부 요청 제거.
- 기본 본문 15px, 행간 1.6, 보조 텍스트 대비 강화. 긴 한글과 입력값은 화면 폭에 맞춰 줄바꿈.
- PCO 화면에 연한 배경과 흰 업무 영역을 구분하고, 최대 너비·모바일 여백을 통일. 운영 현황의 우선 대응 목록과 오늘 일정을 넓은 화면에서 2열로 배치.
- 업체 화면은 배정 업무와 필터를 최근 변경 내역보다 먼저 표시. 선택된 업무 필터 및 현재 메뉴를 배경색과 글자 굵기, aria-current로 구분.
- 공통 표 헤더·행 간격 확대. 서비스 상세 팝업은 항목명 14px, 입력값 16px로 구분.

검증: 전체 자동 테스트 168개 통과. 배포 빌드와 변경 파일 ESLint 확인. 로컬 업체 화면에서 프리텐다드 실제 적용·로드 완료, 가로 넘침 없음, 업무 우선 배치 확인. 기존 데모 데이터 초기화 없음.

범위: 기존 데이터 구조와 처리 절차를 유지한 공통 시각 개선. 모든 개별 입력 폼을 새 디자인으로 재작성하지는 않음.
