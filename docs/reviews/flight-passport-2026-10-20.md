# 항공 업체의 발권용 신원·여권 정보 열람

## 문제와 수정

항공 업체의 예약 화면에 영문 성명 외 여권 정보가 없었고, 기존 민감정보 조회 함수는 PCO·대리인만 허용했습니다. 발권에 필요한 정보를 업체가 확인할 수 없어 업무가 끊겼습니다.

- 항공 상세 팝업과 확정 입력 창에 ‘발권용 여권 정보 열람’ 추가.
- 서비스 ID로 배정 권한을 DB에서 검사한 뒤 해당 대표단의 예약 대상 참가자만 반환. 취소된 참가자는 제외.
- 영문 성명·생년월일·성별·국적·여권번호·발급국·만료일 제공. 건강·알레르기·종교·이동 보조 정보는 새 함수의 반환 형식에도 없음.
- 여권은 현재 게시된 고유식별정보 동의가 유효한 경우만 제공. 미입력·동의 확인 필요·파기를 구분. 정산 완료·업체 소속 해제·미배정·다른 서비스 유형·비로그인 조회 차단.
- 열람 버튼을 누를 때마다 참가자별 필드 목록과 열람자를 기록. 최초 페이지/팝업에는 여권 원문을 넣지 않으며 팝업 닫기·숨기기로 표시 상태 초기화. 다음 조회는 최신 데이터로 다시 검사.
- VIP/PCO의 참가자 추가 및 기존 여권 정보 편집에 생년월일·여권상 성별 연결. 기존 참가자의 영문명·국적도 같은 폼에서 보완 가능. 누락값을 임의 생성하지 않음.
- 실제 발권 기본정보/여권 변경 시 항공 서비스 변경함에 원문 없는 재확인 안내 생성. 확정된 항공은 CHANGING으로 표시하며 기존 예약은 보존. 같은 여권 원문을 다시 암호화한 저장은 재알림하지 않음.

## 검증

독립 조직·계정·가상 여권으로 실제 DB 검증: 배정 항공 업체 열람, 다른 업체/대표단 차단, 민감정보 전체 조회 차단, 열람 기록, 최신 원문 반영, 동의 철회/구버전 동의 차단, 정산·소속 해제 차단, 취소 참가자 제외, 미입력/파기 구분, 파기 후 키 재생성 없음. 변경 안내에 여권 원문이 포함되지 않는지와 동일 원문의 재알림 방지도 검사.

생년월일·성별 검증과 고객 편집의 기존 값 보존, 저장 오류 전달도 자동 테스트에 포함. 날짜만 있는 생년월일·여권 만료일은 해외 시간대에서도 하루 앞당겨 표시되지 않도록 공통 날짜 표시를 보완.

로컬 브라우저에서 항공 데모 → 베트남 대표단 상세 → 여권 열람으로 가상 여권 3명 조회 확인. 팝업을 닫고 다시 열면 여권이 숨겨져 재열람이 필요한 것도 확인. 읽기 전용 검증에서 데모 행사 3개·대표단 6개·참가자 18명·서비스 31건 유지 확인.

## 제한

- 여권 사본 파일·항공사 예약 시스템 연동은 추가하지 않음.
- 기존 데모/고객 데이터에 생년월일·성별 등이 없으면 미입력으로 표시. 실제 여권 대조와 입력 보완은 사용자 업무.
- 이미 열람한 정보를 되돌려 숨길 수는 없으며, 권한·동의 변경은 다음 조회부터 다시 검사.
