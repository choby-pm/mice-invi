# PCO 업무 절감·업체 전달·VIP 확인 개선

## 반영 내용

- DB 권한: 업체는 실제 배정 서비스의 대표단만 조회. 대리인은 자기 요청을 수정할 수 있지만 예약 확정·담당 업체·지원 방식은 변경 불가. 서비스의 행사·테넌트·대표단·유형 변경 차단.
- 항공 데모 계정에 남아 있던 타 분야 4개 업체 소속을 REMOVED로 비활성화. 예약·서비스·업체 레코드는 보존. 로그인 시 활성 소속이 항공 업체 1개인지 검증하며 신규 데모 생성도 동일하게 제한.
- 서비스 상세: 항공 데이터를 숙박 항목에 연결하거나 다른 대표단 참가자를 객실·차량에 배정하는 입력 차단. 취소 요청/취소 완료/지원 제외 서비스의 상세 수정 차단.
- 민감정보: 암호화 키 반환 함수의 외부 실행 권한 회수. 대표단·프로그램 내부 메모는 PCO 전용 테이블로 옮겨 내용 보존. 기존 컬럼은 호환 목적으로 비우며 이전 클라이언트의 입력도 비공개 테이블로 이동.
- 변경 안내: 요청 상세·요약·확정·상태·업체 변경을 DB 저장과 같은 트랜잭션에서 기록. 같은 서비스 열람 권한으로 조회. 최근 20건에 변경 전후, 개인 확인 여부, 업체 확인 여부, 기본 24시간 확인 기한 표시. 확인 기록은 본인만 생성 가능.
- 화면 갱신: PCO 행사·업체·대리인 화면에서 15초마다 갱신. 숨겨진 탭·입력 중·열린 대화상자는 중단. 웹소켓/이메일 발송은 미포함.
- PCO 홈: 운영 현황, 미배정·요청·변경·취소 대기, 미종결 변경, 기한 초과 조정, 참석/명단 누락, 오늘 서비스. 항공보다 이른 픽업, 객실 미배정·중복, 도착 전 숙박 종료 경고.
- 대리인: 배정 대표단이 하나면 바로 이동. 자기 대표단 변경 안내와 기존 요청·확정 조회 연결.
- 취소: 불참은 예약 삭제 없이 취소 요청으로 전달. 업체가 결과·수수료 메모를 입력하고 취소 반영 완료. 참석 재전환은 이미 취소한 예약을 자동 복구하지 않음.
- 동의: 현재 정책·참가자·대표단·항목 관계를 DB에서 검증. 체크 해제는 철회로 일괄 저장. 조회 시 동의 여부와 현재 정책 버전 확인.
- 정산: 서비스와 조정 항목이 미완료이면 정산 불가. PCO가 사유와 함께 완료하면 업체의 서비스·대표단·변경 안내·조정 항목 접근 종료. 재개 가능, 두 행동 모두 감사 기록.
- 예약·연쇄·조정 처리 실패를 성공처럼 숨기지 않고 오류 전달. 각 역할 화면도 함께 갱신.

## 검증

- 독립 테스트 조직·계정으로 실제 DB에서 요청 → 업체 조회 → 확인 기록 → 예약 확정 → 자동 수송 → 고객 변경 → 기존 발권 보존 검증. 미배정 대표단·권한 없는 확정·다른 서비스/참가자 연결·내부 메모·정산 후 접근 차단 포함.
- 동의 버전 불일치·업체의 동의 위조 차단, 동의 철회 검증.
- 기존 행사·대표단·참가자·서비스 초기화 없음. 테스트 생성 데이터는 테스트 소속 ID로만 정리.
- 전체 Vitest 151개, 데모 fixture 7개 통과. 수정한 TypeScript/화면 파일 ESLint, 타입 검사, 배포 빌드 통과.
- 읽기 전용 DB 검증: 행사 3개·대표단 6개·참가자 18명·서비스 31건 유지. 대리인 활성 국가 1개·업체 활성 소속 1개 확인.
- 실제 배포에서 PCO 운영 현황과 VIP 베트남 대표단 직접 진입·변경함 확인. 같은 대리인 세션으로 싱가포르 대표단 URL 직접 접근 시 404 확인. 항공 업체 상세 팝업은 로컬 및 배포 화면에서 확인.

## 운영상 한계와 후속 범위

- 외부 이메일·문자·백그라운드 재알림 미연결. 현재는 인앱 변경함·15초 갱신·기한 초과 표시. 미접속 사용자를 깨우는 전달 수단은 추가 구축 필요.
- 최근 20건은 변경 확인용. 전체 미완료 목록은 서비스 현황·변경 이슈에서 조회. 과거 알림 전체 검색/페이지 이동은 후속 범위.
- 예약 관련 여러 테이블 저장은 아직 단일 트랜잭션이 아님. 오류에서 저장된 부분과 후속 실패를 구분. 동시 편집 잠금·재시도 작업함은 후속 범위.
- 지원 정책 자동 판정, 행사별 필수 필드/마감 설정, 일정표 PDF/엑셀, 보관 기한에 따른 자동 파기는 미포함. 법률 검토·대규모 부하 시험 미수행.
- 운영사 `/admin`은 기존 데모 전용 임시 인증 유지. 실제 조직의 운영사 권한으로 확대하기 전 실제 인증 필요.

## 확인할 화면

1. PCO 담당자로 행사 진입 → 운영 현황과 우선 대응 건.
2. VIP 측 요청 변경 → 항공 업체 전후 비교 → 변경 확인 → 예약 확정.
3. PCO 업체 확인 여부·서비스 상태 → VIP 최신 예약 확인.
4. 미결 상태의 정산 차단 및 정산 후 접근 종료. 공용 데모에 실제 정산을 실행하지 않음.
